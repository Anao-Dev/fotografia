# Evelyn Sousa Fotografia — APT Estúdio

Portfólio da fotógrafa Evelyn Sousa (APT Estúdio, Coelho Neto — Rio de Janeiro), construído em Next.js + GSAP com narrativa de scroll, portfólio editorial e hover-to-play de vídeos.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- React + TypeScript
- GSAP + ScrollTrigger (scroll storytelling, pin, scrub)
- Tailwind CSS 4

## Desenvolvimento

```bash
pnpm dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build de produção

```bash
pnpm build
```

## Estrutura de assets

- `public/images/` — fotografias do estúdio
- `public/videos/` — vídeos dos ensaios
